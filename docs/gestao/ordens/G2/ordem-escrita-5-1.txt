CONTEÚDO DE CADA SEÇÃO:
1. Vetores: vetor-coluna em $\mathbb{R}^n$ (e a notação $\mathbf{x} = (x_1, \dots, x_n)^\top$ para escrever na linha); soma, multiplicação por escalar, combinação linear (apresente o termo aqui: será central nos Temas 5.2 e 5.3); norma; produto escalar $\mathbf{u}^\top\mathbf{v} = \mathbf{u}\cdot\mathbf{v}$; vetor de população: as taxas de $N$ neurônios num instante (ex.: 4 neurônios); interpretação da média de vetores (média de dois padrões de resposta) e da diferença (o que mudou entre dois estímulos). Exemplos: contas com vetores de taxas; a resposta média de uma população a dois estímulos como combinação linear. numpy: np.array, +, *, np.linalg.norm, @ entre vetores.
2. Matrizes: matriz $m \times n$, entrada $a_{ij}$ (linha $i$, coluna $j$); a matriz de dados $\mathbf{X} \in \mathbb{R}^{N \times T}$ neurônios × tempo (linha = série temporal de um neurônio; coluna = vetor de população num instante); outros exemplos de dados como matriz: voxels × estímulos no fMRI, canais × frequências no EEG; soma, multiplicação por escalar, transposta e suas propriedades $(\mathbf{A}^\top)^\top = \mathbf{A}$, $(\mathbf{A}+\mathbf{B})^\top = \mathbf{A}^\top + \mathbf{B}^\top$; média temporal de cada neurônio e "centralizar" os dados (subtrair a média de cada linha) — introduza só a conta, dizendo que será usada no PCA (Tema 5.6). numpy: X.shape, X[i, :], X[:, t], X.T, X.mean(axis=1) — explique axis com cuidado (é uma armadilha clássica).
3. Produto matriz-vetor: definição $(\mathbf{A}\mathbf{x})_i = \sum_j a_{ij}x_j$; as DUAS leituras — (i) cada entrada é o produto escalar de uma linha com $\mathbf{x}$; (ii) $\mathbf{A}\mathbf{x}$ é a combinação linear das colunas de $\mathbf{A}$ com pesos $x_j$; compatibilidade de dimensões; linearidade $\mathbf{A}(\alpha\mathbf{x} + \beta\mathbf{y}) = \alpha\mathbf{A}\mathbf{x} + \beta\mathbf{A}\mathbf{y}$ (demonstração curta recolhível). Exemplo biológico central: rede feedforward linear com 3 neurônios pré-sinápticos e 2 pós-sinápticos, $\mathbf{r}_{\text{pós}} = \mathbf{W}\mathbf{r}_{\text{pré}}$, com $W_{ij}$ = peso da sinapse de $j$ para $i$ (pesos positivos excitatórios, negativos inibitórios) e taxas em Hz; interprete linha $i$ de $\mathbf{W}$ = "o que o neurônio $i$ escuta" e coluna $j$ = "para onde o neurônio $j$ fala". Diga explicitamente que neurônios reais não são lineares (o modelo linear é uma primeira aproximação; não-linearidades aparecem no Módulo 9). numpy: W @ r.
4. Produto de matrizes: definição $(\mathbf{A}\mathbf{B})_{ij} = \sum_k a_{ik}b_{kj}$; regra das dimensões $(m\times n)(n\times p) = m\times p$; produto como composição: duas camadas lineares $\mathbf{r}_2 = \mathbf{W}_2(\mathbf{W}_1\mathbf{r}_0) = (\mathbf{W}_2\mathbf{W}_1)\mathbf{r}_0$ (por isso empilhar camadas lineares não aumenta o poder do modelo — fato que motiva as não-linearidades do Módulo 9); associatividade, NÃO comutatividade (contraexemplo 2×2 explícito), matriz identidade $\mathbf{I}$, $(\mathbf{A}\mathbf{B})^\top = \mathbf{B}^\top\mathbf{A}^\top$; produto aplicado a uma gravação inteira: $\mathbf{W}\mathbf{X}$ transforma todos os instantes de uma vez; menção de que a inversa vem no Tema 5.2. numpy: @ versus * (produto elemento a elemento) — armadilha obrigatória.
