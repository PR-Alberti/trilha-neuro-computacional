Seções que a aula deveria cobrir (definidas pelo gestor), com o conteúdo esperado:
1. sec:7-2-1 "Espaço amostral, eventos e variáveis aleatórias" — experimento aleatório, espaço amostral Ω, evento; axiomas de Kolmogorov em linguagem simples (P(A) ≥ 0, P(Ω) = 1, aditividade para eventos disjuntos) e consequências (complemento, P(A∪B) = P(A)+P(B)−P(A∩B)); independência P(A∩B) = P(A)P(B); variável aleatória como função que associa um número a cada resultado; discreta × contínua; função de probabilidade (pmf) p(x) = P(X = x); densidade (pdf) f(x) com P(a ≤ X ≤ b) = ∫_a^b f(x) dx; função de distribuição acumulada F(x) = P(X ≤ x). Armadilha comum: a densidade não é uma probabilidade (pode ser maior que 1) e P(X = x) = 0 para X contínua. Exemplos: número de spikes num ensaio (discreta) × potencial de membrana medido (contínua); soma de dois dados.
2. sec:7-2-2 "Esperança e variância" — E[X] = Σ x p(x) e E[X] = ∫ x f(x) dx; interpretação como centro de massa e média de longo prazo; Var(X) = E[(X − μ)^2] = E[X^2] − (E[X])^2 (demonstração curta); desvio-padrão; propriedades: E[aX + b] = aE[X] + b, Var(aX + b) = a^2 Var(X), E[X + Y] = E[X] + E[Y] sempre e Var(X + Y) = Var(X) + Var(Y) quando X e Y são independentes. Exemplos: um dado (E = 3,5, Var = 35/12); converter a variância de mV² para V² ao trocar a unidade (Var(aX) = a² Var(X) com a = 10⁻³).
3. sec:7-2-3 "Distribuições discretas: Bernoulli, binomial e Poisson" — pmf, E e Var de cada uma (Bernoulli: p, p(1−p); binomial: C(n,k)p^k(1−p)^(n−k), np, np(1−p), derivadas pela soma de Bernoullis independentes; Poisson: e^(−λ)λ^k/k!, λ, λ); a Poisson como limite da binomial com n grande, p pequeno e np = λ fixo (ideia em prosa, citando o limite (1 − λ/n)^n → e^(−λ) do Módulo 2). Exemplos biológicos obrigatórios: liberação quântica de neurotransmissor (hipótese quântica de Katz): sinapse com n = 10 sítios, cada um liberando uma vesícula com p = 0,3 independentemente — P(nenhuma liberação) = 0,7^10 ≈ 0,0282, E = 3, Var = 2,1; contagem de spikes de um neurônio que dispara a 20 Hz numa janela de 200 ms: X ~ Poisson(λ = 20·0,2 = 4), P(X = 0) = e^(−4) ≈ 0,0183, P(X = 4) = e^(−4)·4^4/4! ≈ 0,195 — confira. Fator de Fano Var/E = 1 para a Poisson (referência clássica para a variabilidade de contagens de spikes). Código: scipy.stats.binom/poisson (.pmf, .cdf, .mean, .var) e conferência por simulação com rng.
4. sec:7-2-4 "Distribuições contínuas: uniforme, exponencial e normal" — pdfs, E e Var: uniforme em [a,b] ((a+b)/2 e (b−a)^2/12), exponencial com taxa λ (λe^(−λx), 1/λ, 1/λ^2, F(x) = 1 − e^(−λx), falta de memória P(X > s+t | X > s) = P(X > t) — defina probabilidade condicional P(A|B) = P(A∩B)/P(B) quando usá-la), normal N(μ, σ^2) (pdf, regra 68–95–99,7, padronização Z = (X − μ)/σ). Exemplos biológicos obrigatórios: intervalos entre spikes (ISI) de um neurônio de Poisson a 20 Hz são exponenciais com média 50 ms; P(ISI > 100 ms) = e^(−20·0,1) = e^(−2) ≈ 0,135; ruído de medida do potencial de repouso ~ N(−70, 2^2) em mV: P(V > −67) = P(Z > 1,5) ≈ 0,0668 — confira. Armadilha comum: a exponencial real dos ISIs tem um período refratário que a Poisson ignora (diga que é uma idealização). Código: scipy.stats.expon (atenção: scale = 1/λ), scipy.stats.norm, histogramas de amostras de rng com a pdf sobreposta.
