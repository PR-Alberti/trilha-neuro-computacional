Como usar o guia

Recomendações de método para não se perder em ~380 horas de estudo.

  1. Uma seção por vez — no máximo duas em paralelo (ex.: matemática + programação).
  2. Regra dos 50%: metade do tempo de cada módulo deve ser prática. Assistir vídeo não é estudar.
  3. Após cada subseção, gere exercícios com uma IA — cada tema desta página traz o prompt pronto para copiar.
  4. O teste da seção fecha o módulo: sem ele, o módulo não acabou.
  5. Verde primeiro; os itens âmbar entram na segunda passada ou quando um projeto real exigir.
  6. Antecipe o contato com a área: leia resumos de artigos de encoding/decoding e acompanhe comunidades como o Neuromatch para criar vocabulário e manter a motivação.
